## ✨ Key Features & Engineering Highlights

- **3D Scroll-Linked Turning Card Engine**: Custom `requestAnimationFrame` loop driving 180° rotation of the creator avatar into the EDC tech flatlay as you scroll from Hero into Services & About.
- **Sticky Stacking Project Deck**: Dynamic distance and scale calculations stacking 3 high-impact backend projects as the user scrolls, paired with interactive 3D mouse perspective tilt.
- **Modern Minimal Notched Cards**: Sleek top-right shelf cutout styling with verified brand badges, 3-column system metrics, and gradient pill buttons.
- **Seamless Dual Theme Engine**: Portavia-inspired high-contrast dark theme (`#0f0f0f` / `#18181b` with `#d0ff71` accent) and clean light theme with `localStorage` persistence.
- **3D Rolling Navbar**: Pill-shaped floating navbar with cube-roll hover physics and mobile drawer support.
- **Direct Connect & Social Hub**: Large glowing brand cards for GitHub, LinkedIn, and direct email dispatch.
- **100% Self-Contained**: Embedded base64 graphics, pure SVG icons, and zero render-blocking dependencies for ultra-fast First Contentful Paint (< 0.2s).

## 🛠️ Built With

- **HTML5**: Semantic layout, accessible interactive dialogs, embedded SVGs.
- **CSS3**: CSS Custom Properties (Theme tokens), CSS Grid, Flexbox, `perspective`, `preserve-3d`, `rotateY()`, sticky positioning.
- **JavaScript (Vanilla ES6+)**: Scroll physics tracking, deck stacking math, 3D mouse tracking, theme switcher, modal manager.
